Оценка карточек: вариант A

«Нет» — только влево, всё «да» — вправо: → помню, ↗ легко, ↘ с трудом. Во время свайпа фон карточки заливается цветом ответа, без надписей. Цвета: красный — нет, оттенки одного зелёного — да (светлее — с трудом, темнее — легко). На Mac: пробел открывает, ← → ↑ ↓ оценивают, пробел после открытия = помню, Z отменяет. Клик по устройству даёт ему клавиатуру.
